## Foreword
Great gardens are systems of interdependent parts, and strong software mirrors that
structure. This module builds your programming skills by growing a digital garden
ecosystem where each component has a clear role.


## Introduction
You will progress from basic program structure to object-oriented programming by
building a cohesive garden management system. The exercises emphasize reusable
components, clean organization, and scalable design.

## General Instructions
- Python 3.10+ only.
- Code must respect flake8 standards.
- Each exercise must be in its own file.
- Use naming conventions: classes in PascalCase, functions and variables in
  snake_case.
- Include docstrings for functions, classes, and methods.
- All functions and methods must include type hints.
- No input validation unless explicitly mentioned.
- Programs must always run without errors.
- From Exercise 1 onward, classes are required.
- You may use `if __name__ == "__main__":` blocks for testing.
