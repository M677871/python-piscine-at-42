## Description

Data Quest teaches you to master Python's collection types: lists, tuples, sets, dictionaries, generators, and comprehensions. Build a game analytics platform through 7 progressive exercises.

## Exercises

- **ex0**: Command Quest - Learn command-line arguments (sys.argv)
- **ex1**: Score Cruncher - Process data with lists
- **ex2**: Position Tracker - Handle coordinates with tuples  
- **ex3**: Achievement Tracker - Track unique items with sets
- **ex4**: Inventory System - Use dictionaries for data storage
- **ex5**: Data Stream - Process data efficiently with generators
- **ex6**: Analytics Dashboard - Transform data with comprehensions

## Requirements

- Python 3.10+
- Follow flake8 coding standard
- Include type hints on all functions
- Handle errors gracefully
- Only sys module allowed for CLI processing
- No file I/O (process in-memory only)
