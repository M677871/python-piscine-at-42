## Description

Learn file operations and resource management as a Data Archivist. Master reading, writing, and safely handling files using Python's file I/O capabilities and context managers.

## Exercises

- **ex0**: Ancient Text Recovery - Read files with open(), read(), close()
- **ex1**: Archive Creation - Write files with open(), write(), close()
- **ex2**: Stream Management - Use sys.stdin, sys.stdout, sys.stderr
- **ex3**: Vault Security - Safe file handling with the 'with' statement
- **ex4**: Crisis Response - Handle file errors with try/except blocks

## Requirements

- Python 3.10+
- Follow flake8 coding standard
- Include type hints on all functions
- Handle exceptions gracefully
- Use 'with' statement for file operations (context managers)
- Proper error handling for FileNotFoundError, PermissionError, etc.

## Key Topics

- **File Operations**: open(), read(), write(), close()
- **Streams**: stdin, stdout, stderr
- **Context Managers**: The 'with' statement
- **Error Handling**: try/except blocks
- **Resource Management**: Automatic file closing
