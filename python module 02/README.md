## Foreword
Agricultural data systems face real-world turbulence: faulty sensors, dropped
connections, and corrupted readings. This module focuses on designing resilient
pipelines that handle the unexpected without breaking.


## Introduction
You will learn how to validate and clean data streams, identify failure modes in IoT
sensor networks, create custom agricultural alerts, and build fault-tolerant monitoring
systems that preserve data integrity under real-world conditions.

## General Instructions
- Python 3.10+ only.
- Code must respect flake8 standards.
- All functions and methods must include type hints.
- Each exercise must be in its own file.
- Show both normal operations and error scenarios.
- Use try/except blocks for error handling in every exercise.
- Programs must never crash.
- Built-in exceptions may be used as needed (e.g., ValueError, TypeError,
  ZeroDivisionError, FileNotFoundError, KeyError, IndexError, AttributeError,
  Exception).
