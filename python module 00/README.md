# Growing Code - Python Fundamentals Through Garden Data

## Description
Growing Code is an educational project designed to teach Python fundamentals through real-world community garden scenarios. The goal is to help learners understand core Python concepts—such as expressions, variables, functions, and control flow—by creating practical programs that manage garden data, including plant growth, harvest tracking, water reminders, and seed inventory.
