## How to run

Requirements:

- Python 3.8 or newer

Run an exercise from its directory. Example commands:

Windows:

```powershell
py ft_hello_garden.py
```

Linux / macOS:

```bash
python3 ft_hello_garden.py
```

Replace the filename with the script you want to execute (for example, `ft_plot_area.py`).

## Skills & concepts covered

- Python syntax and execution model
- Function design and modularity
- Primitive and compound data types (lists, tuples, dicts)
- Conditional logic and iteration
- Simple I/O and validation
- Writing clear, testable, evaluator-friendly code

## Coding standards

- Follow 42 coding culture and piscine rules; do not use external libraries unless explicitly permitted by an exercise.
- Prefer deterministic functions with minimal side effects and clear return values.
- Follow PEP 8 conventions where practical while respecting piscine constraints.
